# 🎂 Age Calculator

A simple and interactive Age Calculator built using HTML, CSS, and JavaScript. It allows users to calculate their exact age based on their date of birth.

## 📌 About the Project

The Age Calculator is a beginner-friendly frontend web application that calculates a person's age from their date of birth to the current date.

It displays the age in years, months, and days through a simple and user-friendly interface.

## ✨ Features

- 🎂 Enter date of birth
- 📅 Calculate exact age
- 📊 Display age in years, months, and days
- ⚡ Instant calculation
- ❌ Input validation
- 🎨 Modern and attractive user interface
- 📱 Fully responsive design

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Age calculation and functionality
